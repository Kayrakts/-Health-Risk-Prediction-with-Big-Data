# Büyük Veri Teknolojileri ile Sağlık Risk Tahmini

## Proje Hakkında
PySpark kullanılarak 319.795 satırlık CDC sağlık veri seti üzerinde 
kalp hastalığı risk faktörleri analiz edilmiştir. Decision Tree, Random 
Forest ve Gradient Boosting algoritmaları karşılaştırılmış; %91,6 test 
doğruluğuyla Gradient Boosting modeli tercih edilmiştir.

## Kullanılan Araçlar
- Python (PySpark, Scikit-learn, Pandas)
